# Sample medical records

Synthetic files for demonstrating the upload -> encrypt -> IPFS -> blockchain
flow. **No real patient data appears here and none should ever be uploaded to
this system** - it runs on a public Ethereum testnet.

| File | Record type to select |
|------|----------------------|
| `blood-report.txt` | Lab Report |
| `prescription.txt` | Prescription |
| `discharge-summary.txt` | Discharge Summary |

Any PDF, PNG or JPEG up to 15 MB also works.
